# infrai
AI for Infra

Set virtual environment:
python3 -m venv <name>

Note: Exclude the folder <name> from your git branch

Activate virtual environment:
source <name>/bin/activate

Install packages:
pip3 install -r requirments.txt

Setup environment:
1. Create file called .env in the same folder.
2. In the .env file type:
	OPENAI_API_KEY=<key>
Replace the <key> with the actual key from your platform profile at https://platform.openai.com
Note: Exclude the .env file from your git branch
